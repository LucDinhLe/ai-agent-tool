# AI Agent Tool v2.2.0 — Claude Cowork chuyển sang khai sinh Markdown thuần

Bản này thay toàn bộ adapter Claude Cowork bằng một bộ khai sinh mới, đơn giản hơn và trung thực hơn với những gì Cowork thực sự hỗ trợ. Năm nền tảng còn lại (Codex, Claude Code, Gemini CLI, GitHub Copilot, OpenClaw) không đổi kiến trúc.

## Vì sao đổi

Claude Cowork không có cơ chế tự khám phá local skill hay `.ai-agent/` runtime theo project folder như Claude Code. Bản `AI-Agent-Tool/` cũ mô phỏng kiến trúc skill chung của cả bộ, nhưng phải vá thêm bước upload skill riêng cho tài khoản mới dùng được `@agents`, khiến trải nghiệm Cowork rườm rà hơn cách nó thực sự vận hành. `khai-sinh/` bỏ hẳn lớp skill: chỉ còn file Markdown ở root, agent tự đọc theo thứ tự cố định trong `CLAUDE.md`.

## Thay đổi chính

- **Folder cài đặt đổi tên**: `AI-Agent-Tool/` → `khai-sinh/`.
- **Không còn `@agents`**: kích hoạt bằng cách paste `khai-sinh/COWORK-PROJECT-INSTRUCTIONS.txt` vào Project Instructions một lần, mở phiên mới và gõ "bắt đầu đi".
- **Không còn SKILL.md hay `.ai-agent/`**: danh tính, người dùng, bài toán và ký ức chắt lọc nằm thẳng ở `IDENTITY.md`, `USER.md`, `PROJECT.md`, `MEMORY.md` tại root.
- **Nghi thức khai sinh nằm trong `BOOTSTRAP.md`**, tự chuyển vào `_archive/` sau khi hoàn tất thay vì một birth skill riêng.
- **Bỏ `AI-Agent-Tool-Claude-Cowork-Skill.zip`** khỏi luồng phát hành vì không còn skill nào để upload qua Customize.
- File `HUONG-DAN.md` mới thay cho `START-HERE.md`, viết lại toàn bộ hướng dẫn cài đặt cho luồng này.

## Cách cài Claude Cowork

1. Tải `AI-Agent-Tool-Claude-Cowork.zip`, giải nén, bên trong chỉ có `khai-sinh/`.
2. Copy `khai-sinh/` vào folder chính của dự án, kết nối folder đó với Cowork.
3. Paste nội dung `khai-sinh/COWORK-PROJECT-INSTRUCTIONS.txt` vào Project Instructions.
4. Mở phiên mới, gõ "bắt đầu đi". Agent tự dẫn qua nghi thức khai sinh trong `BOOTSTRAP.md`.

Năm gói còn lại cài như cũ, xem README hoặc [bảng hỗ trợ nền tảng](../PLATFORM-SUPPORT.md).

## Kiểm thử phát hành

- `AI-Agent-Tool-Claude-Cowork.zip` chỉ có đúng một top-level folder `khai-sinh/`.
- Bỏ kiểm thử ZIP kỹ năng riêng cho Cowork vì gói đó không còn được phát hành.
- Validator cập nhật: `khai-sinh/` được kiểm required files, TODO chưa giải quyết, và `COWORK-PROJECT-INSTRUCTIONS.txt` phải trỏ đúng về `CLAUDE.md`/`BOOTSTRAP.md`.
- Năm bundle còn lại giữ nguyên bộ kiểm thử của v2.1.0.
