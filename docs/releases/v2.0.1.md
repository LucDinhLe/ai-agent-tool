# AI Agent Tool v2.0.1 — Chọn nền tảng ngay sau khi giải nén

Bản vá này sửa trải nghiệm tải xuống. Sáu folder nền tảng được đưa lên cấp đầu của Source code và của gói tổng để người dùng nhìn thấy ngay sau khi giải nén.

## Nên tải file nào?

Tải `AI-Agent-Tool-CHON-NEN-TANG-v2.0.1.zip`.

Sau khi giải nén, sáu folder xuất hiện ngay ở cấp đầu:

1. `01-CODEX/`
2. `02-CLAUDE-CODE/`
3. `03-CLAUDE-COWORK/`
4. `04-GEMINI-CLI/`
5. `05-GITHUB-COPILOT/`
6. `06-OPENCLAW/`

Chọn một folder, mở nó và copy toàn bộ nội dung bên trong vào root dự án. Mỗi folder vẫn là một bundle độc lập và đầy đủ.

## Những gì giữ nguyên

- Birth protocol và contract `@agents` của v2.0.0.
- Các ZIP riêng cho từng nền tảng.
- Vùng memory private được ignore mặc định.
- Lệnh native dự phòng theo từng host.

Claude Cowork vẫn cần dán `COWORK-PROJECT-INSTRUCTIONS.txt` vào Project Instructions một lần hoặc upload skill ZIP.

Tất cả file phát hành có checksum trong `SHA256SUMS.txt`.
