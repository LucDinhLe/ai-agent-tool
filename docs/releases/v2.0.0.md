# AI Agent Tool v2.0.0 — Copy, paste, birth

v2 turns the original Markdown templates into standalone, host-aware bundles.

## Why this exists

Strong models still need stable project instructions, verified context, reusable workflows, memory boundaries and a clear authorization contract. AI Agent Tool supplies that project layer without retraining the model or expanding its permissions.

Without it, the AI still works, but users often repeat context, re-explain preferences, recover forgotten decisions and correct host-specific setup by hand.

## Install

1. Download the ZIP matching your host.
2. Extract and copy every file, including dot-directories, into the project or workspace root.
3. Merge an existing host entry file instead of overwriting it.
4. Start a new session and invoke the bundle's birth command.

| Host | Primary invocation | Native fallback |
|---|---|---|
| Codex desktop | `@agents` | Codex CLI/IDE: `$agents` |
| Claude Code | `@agents.md` file mention | `/agent-birth` |
| Claude Cowork | `@agents` after Project Instructions | Uploaded `/agent-birth` skill |
| Gemini CLI | `@agents` | `/ai-agent:init` |
| GitHub Copilot | portable alias `@agents` | `/agent-birth` |
| OpenClaw | native first-run bootstrap | `/skill agents` or `$agents` |

Claude Cowork currently requires the one-time Project Instructions step documented inside its bundle; Anthropic does not publish a zero-config local instruction-file contract for Cowork projects.

## What birth creates

- Stable agent identity and collaboration style.
- Verified project source of truth.
- Optional portable memory with `off`, `minimal` and `full` modes.
- Explicit confirmation boundaries.
- A birth card and structural doctor report.

AI Agent Tool remains a context/workflow layer. Host sandboxing, permissions, hooks, firewall, connectors and approvals remain authoritative.

Verify downloads with `SHA256SUMS.txt`.
