# AI Agent Tool v2.1.0 — Một ZIP, một folder

Phiên bản này sửa trực tiếp điểm gây khó khăn lớn nhất của v2.0.1: người dùng không còn tải một gói tổng, chọn giữa nhiều folder rồi mở folder để tự copy nhiều file vào root dự án.

> **Không tải “Source code (zip)” để cài.** Hãy chọn đúng asset `AI-Agent-Tool-<nền-tảng>.zip` trong phần Assets. “Root dự án” là folder chính của dự án mà AI đang mở.

## Trải nghiệm mới

1. Chọn công cụ AI đang dùng trên README hoặc trang Release.
2. Tải đúng một ZIP.
3. Giải nén để nhận đúng một folder.
4. Copy nguyên folder vào dự án.
5. Mở phiên AI mới và kích hoạt.

| Gói | Folder duy nhất | Kích hoạt chính |
|---|---|---|
| Codex | `.agents/` | `@agents` desktop, `$agents` CLI/IDE |
| Claude Code | `.claude/` | chọn `agents (agent)` từ `@agents`, hoặc `/agent-birth` |
| Claude Cowork | `AI-Agent-Tool/` | Project Instructions một lần, rồi `@agents` |
| Gemini CLI | `.gemini/` | `@agents` |
| GitHub Copilot | `.github/` | `/agent-birth` |
| OpenClaw | `skills/` | `/skill agents`; `$agents` trong Control UI/WebChat |

## Điều gì xảy ra sau khi kích hoạt?

Adapter kiểm tra project trước, tạo hoặc hợp nhất các file runtime cần thiết, hỏi các lựa chọn không thể suy ra, ghi state và trả birth card. Nó không ghi đè file hướng dẫn đang có một cách âm thầm.

Các file như `.ai-agent/`, `AGENTS.md` hoặc `GEMINI.md` không còn nằm rời trong ZIP cài đặt. Chúng là kết quả của birth flow.

## Tương thích trung thực

- `@agents` là native skill selection trong Codex desktop và native subagent invocation trong Gemini CLI.
- Claude Code yêu cầu chọn `agents (agent)` từ typeahead; cú pháp chính xác là `@agent-agents`, fallback `/agent-birth`.
- Cowork cần Project Instructions hoặc skill cài qua Customize vì Anthropic chưa công bố local auto-discovery contract tương đương Claude Code.
- GitHub Copilot dùng `/agent-birth`; `@agents` chỉ là alias best-effort.
- OpenClaw dùng `/skill agents` trên mọi bề mặt; `$agents` là shortcut của Control UI/WebChat; `/agents` là lệnh built-in khác.

## Kiểm thử phát hành

- Mỗi platform ZIP chỉ có đúng một top-level folder.
- Cowork account skill ZIP có đúng một top-level skill folder `agent-birth/` theo contract upload của Anthropic.
- Không có gói tổng hoặc wrapper thừa.
- Kiểm tra CRC, path traversal, symlink, dữ liệu private, file tạm và checksum SHA-256.
- Kiểm tra bootstrap resources, invocation routing, version, state, marker merge và skill metadata.
