# Initialize or maintain the project agent

1. Locate the connected project folder containing `.ai-agent/BIRTH.md`.
2. Read `.ai-agent/BIRTH.md` and `.ai-agent/STATE.md` completely.
3. Determine the requested mode. Default to `init` when uninitialized and `status` when initialized.
4. Follow the protocol while keeping all writes inside the connected project folder.
5. Preserve existing user content and ask before discarding material information.
6. Never request, copy, print or store credentials. Keep portable private context under `.ai-agent/private/`.
7. Finish with the required birth card or doctor report.

If the connected folder does not contain the protocol, report that the project bundle is incomplete and stop.
