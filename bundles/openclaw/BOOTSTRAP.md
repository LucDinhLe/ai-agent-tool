# First-run birth

This is a one-time OpenClaw bootstrap file.

On the first real user interaction, or when the user invokes `@agents`, read `.ai-agent-tool/BIRTH.md` and `.ai-agent-tool/STATE.md` completely, then run `init`.

After the birth proposal is confirmed, the native identity and memory files are updated, privacy checks pass and the birth card is returned, delete this `BOOTSTRAP.md` file. Keep the `agents` skill for later status, doctor and reconfiguration calls.

Do not delete this file if initialization fails or remains unconfirmed.
