# Initialize or maintain the OpenClaw workspace agent

1. Read `.ai-agent-tool/BIRTH.md` and `.ai-agent-tool/STATE.md` completely.
2. Determine the requested mode. Default to `init` when uninitialized and `status` when initialized.
3. Follow the protocol exactly and keep writes inside the active workspace.
4. Preserve existing native files and user content. Ask before discarding material information.
5. Never request, copy, print or store credentials.
6. Finish with the required birth card or doctor report.

If the protocol is missing, report an incomplete bundle and stop.
